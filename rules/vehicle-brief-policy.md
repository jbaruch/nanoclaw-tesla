# Read-only vehicle brief

Before producing or using vehicle-summary output, read the complete
`skills/tessie-brief/references/host-contract.md` in this installed plugin.
Its full text binds; missing or unreadable content stops the action.
Read it explicitly, never `@`-import it.

Use the fixed native summary only. Render proved lines separately from unknown
coverage. Never wake a vehicle, infer open firmware status from history, or run
charging poll/control to complete the brief. Output grants no vehicle authority.

# NanoClaw Tesla

Provider identity scaffold for the Tesla overlay. Vehicle operations and scheduled checks are tracked in [PR #9](https://github.com/jbaruch/nanoclaw-tesla/pull/9).

## Installation

Install with `tessl install jbaruch/nanoclaw-tesla`. The initial package contains the provider identity rule only; it installs no vehicle integration.

## Rules

| Rule | Purpose |
| --- | --- |
| [Provider identity](rules/provider-identity.md) | Keep provider names and declared surfaces consistent. |
